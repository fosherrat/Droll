# DRL-P3 · Step 0 · 요구사항과 설치 공간 (draft)

Part 3(휠 모듈)의 부품 선정과 모델링에 들어가기 전에 고정해야 할 숫자들.
모든 값의 원본은 `droll/params.py`, 계산은 `part3/analysis/requirements_check.py`,
계산 결과 표는 `docs/part3/generated/req_tables.md`, 그림은 `docs/part3/generated/envelope.png`.

좌표계: 원점 = 구 중심, +y 위, 단위 mm. 방위각 0°는 +x(프롭 0° 방향).

## 1. 이 모듈이 해야 하는 일 (기능 요구)

| ID | 요구 | 근거 |
|---|---|---|
| F1 | 닫힌 셸을 임의 방향으로 굴리고, 동시에 수직축 회전(yaw)도 만든다 | 볼봇 방향 3휠, 스텝 1·2 |
| F2 | 셸을 프레임 기준 ±1.5° 안으로 정렬할 수 있다 (페탈 패드 ↔ 푸시로드) | 스텝 2 Align |
| F3 | 리드스크류로 들어올려 바퀴가 셸에서 떨어진다: 리프트 15–25 mm | 스텝 3, Part 2 인터페이스 |
| F4 | 바퀴는 무전원일 때 손으로 돌아가야 한다 (역구동 가능, 웜 금지) | 디버깅, 옴니휠 제어 |
| F5 | 스프링 서스펜션: 정하중에서 스톱 대비 2.7 mm, 범프 10 mm | 페탈 닫힘 타이밍 |
| F6 | 휠마다 쿼드러처 엔코더 | 속도 제어, F2 |

## 2. 성능 목표

| 항목 | 값 | 상태 |
|---|---|---|
| 일반 주행 속도 | 0.5 m/s | 가정 — 확인 필요 |
| 최고 속도 (설계 케이스) | 1.0 m/s + 동시 yaw 90°/s | 가정 |
| 가속 | ≥ 0.5 m/s² | 계산상 0.78 (프레임 30° 기울기) |
| 등판 | 실내 평지, 경사 ≤ 4° | COM −50 mm 기준 4.5° |
| 모듈 질량 | **목표 ≤ 500 g**, 상한 760 g (현 v1 추정) | 제안 — 예산은 380 g |

> 구동 토크 한계는 모터가 아니라 **진자(프레임 무게중심 높이)**가 정한다.
> COM이 −50 mm면 휠 피크 토크 0.107 N·m로 충분하고, 모터를 키워도 더 빨리 가속하지 않는다.
> COM을 −80 mm로 내리면 가속·등판이 약 1.7배가 되고 휠 토크 요구는 0.19 N·m로 오른다 (민감도 표 참고).

## 3. 설치 공간 (계산 결과)

| 항목 | 값 |
|---|---|
| 접촉점 (25°) | r 103.1, y −221.1 |
| 휠 중심 (Ø58) | r 90.9, y −194.9 |
| 바닥 사각형 220 평면 | y −160.7 |
| 휠 → 바닥 스트럿 최소거리 | 0 mm 리프트 16.3, 22.5 mm 리프트 6.1, **39 mm에서 접촉** (휠만, 포드 몸체 제외) |
| 휠 → 프롭 디스크 | 22.5 mm 리프트에서 38 mm |
| 허브 → 배터리 선반 | 22.5 mm 리프트에서 **5.5 mm**, 28 mm에서 접촉 |
| 프롭 팁 → 셸 내면 | 4.3 mm (Part 3 아님, 참고) |

### 새로 확인된 제약: 모터는 바퀴의 **극(아래) 쪽**에 둬야 한다
안쪽(구 중심 방향)으로 향하는 25 mm급 모터의 최대 몸체 길이:

| 베벨 위치 | 최대 길이 | 막는 것 |
|---|---|---|
| 적도 쪽 (위) | 52 mm | 0° 휠 위의 프롭 디스크 (+10 mm 여유) |
| **극 쪽 (아래)** | **86 mm** | 허브 플레이트 (그다음 리드너트 94 mm) |

GA25-370 + 엔코더는 보통 65–75 mm라서 극 쪽에서만 들어간다. 1단계 후보는 **몸체 ≤ 80 mm** (5 mm 여유)로 거른다.

## 4. 부품 요구 (1단계 선정 기준)

### 모터 (휠 1개당, 휠 축 기준)
| 항목 | 값 |
|---|---|
| 부하 속도 | 345 rpm (1.0 m/s + 90°/s) |
| 무부하 속도 | ≥ 460 rpm (목표 450–600) |
| 연속 토크 | 0.07 N·m |
| 피크 토크 (손실 1.5×) | 0.11 N·m |
| 스톨 토크 | ≥ 0.32 N·m |
| 피크 기계 출력 | 4 W |
| 전압 | 12 V (6S에서 벅) |
| 엔코더 | 휠 1회전당 ≥ 340 카운트 (트레드 ≤ 0.54 mm/카운트) |
| 크기 | Ø ≤ 25, 몸체 ≤ 80 mm (엔코더 포함), 질량 ≤ 100 g |
| 역구동 | 가능해야 함 (웜 기어모터 제외) |

### 옴니휠
| 항목 | 값 |
|---|---|
| 형식 | 이중열(double-row), 고무 롤러 |
| 지름 | 48–60 mm (현재 58 가정) |
| 폭 | ≤ 25 mm (공간 계산에 쓴 값) |
| 하중 | 정하중 10.6 N, 범프 1.5× 16 N, 롤러 Ø ≥ 10 |
| 축 | Ø4–6, 베벨 기어나 커플러를 달 수 있어야 함 |
| 질량 | ≤ 40 g |
| 우선 | 제조사 STEP 제공 |

## 6. 다음 단계 (1단계: 부품 선정) 입력
- 위 4절 표로 모터·옴니휠 후보를 2–3개씩 뽑아 비교표 작성 (스펙시트, 가격, 무게, 구매처, STEP 유무).
- 비교할 구조 옵션: (a) 25 mm 기어모터 + 1:1 프린트 베벨, 극 쪽 배치 (현재안) / (b) 소형 90° BLDC 일체형 / (c) N20급 소형 기어모터 2배 감속 — 무게 목표 500 g 때문에 (c)도 검토.
